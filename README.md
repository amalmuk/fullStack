# FullStackPro - Angular & Next.js

## Project Overview
This project is part of TP1: Building a Full Stack Web Application.
It contains two frontend applications developed with Angular and Next.js.

## Technologies Used
- Angular
- Next.js
- TypeScript
- HTML and CSS
- Git and GitHub

## Project Structure
- ngapp/: Angular application
- nxapp/: Next.js application

## Features
- Home page
- Login page with form validation
- Contact page with form validation
- Navigation between pages

## How to Run Angular
cd ngapp
npm install
npx ng serve

Open http://localhost:4200.

## How to Run Next.js
cd nxapp
npm install
npm run dev

Open http://localhost:3000.
